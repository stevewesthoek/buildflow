# Agent Runtime v1.1

## Boundary
Custom GPT remains the reasoning and coding engine. BuildFlow local remains a deterministic control plane: validation, compact progress, safety, and Git workflows. This version does not add a local or paid LLM executor.

## Implemented
- Added a compact persistent Agent Runtime event log in `packages/cli/src/agent/agent-events.ts`.
- Added run-level pause/resume/cancel helper in `packages/cli/src/agent/agent-jobs.ts`.
- Updated deterministic local preflight to emit compact events and observe paused/cancelled states.
- Added local `/api/agent-jobs/control` endpoint for compact event polling and run controls.
- Added GPT/web action route `/api/actions/agent/control` and transport function `controlBuildFlowAgentRun`.
- Updated OpenAPI schema source and GPT instructions to expose the control action.
- Updated GPT action contract verification to include the new action.

## Operating model
1. GPT starts an Agent Mode job with a compact goal.
2. Local BuildFlow creates the ledger and emits compact runtime events.
3. Local BuildFlow runs deterministic preflight and validation.
4. GPT polls `controlBuildFlowAgentRun` with `action: events` for compact progress, or uses pause/resume/cancel.
5. GPT performs reasoning/coding only when needed and uses low-level read/write/command tools sparingly.
